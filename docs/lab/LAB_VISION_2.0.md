## 🎯 Lab Exercises: Splunk-Focused

### Exercise 1: Self-Referential Query
**Goal:** Prove the lab can teach itself

**Task:**
1. Ask the RAG: "What is RAG and why does it matter for enterprises?"
2. Observe the metrics:
   - Groundedness score (should be 0.9+)
   - Retrieved sources (AI_FUNDAMENTALS.md)
   - Latency (<300ms)
3. Ask follow-up: "How does Splunk monitor RAG systems?"
4. Compare metrics (is the second query faster? Why?)

**Learning:**
- How RAG works (by using RAG!)
- How Splunk measures quality (groundedness)
- How to interpret metrics

---

### Exercise 2: Cost Forecasting with MLTK
**Goal:** Show MLTK value for optimization

**Task:**
1. Ask 10 different queries, observe cost metrics
2. Export metrics to CSV (from metrics dashboard)
3. Load into Splunk (via HEC or manual upload)
4. Run MLTK Smart Forecasting Assistant:
   ```spl
   | inputcsv rag_metrics.csv
   | timechart span=1h sum(cost) as hourly_cost
   | fit StateSpaceForecast hourly_cost forecast_k=24
   | eval daily_cost = predicted_hourly_cost * 24
   | stats sum(daily_cost) as monthly_cost_forecast
   ```
5. Answer: "If I deploy this to 1,000 users, what's the monthly cost?"

**Learning:**
- How to export RAG metrics
- How to use MLTK for forecasting
- How to calculate ROI for customers

---

### Exercise 3: Anomaly Detection
**Goal:** Show Splunk detects performance issues

**Task:**
1. Simulate slow query (toggle re-ranking ON)
2. Ask 5 queries, observe latency spike
3. Use MLTK Outlier Detection:
   ```spl
   | inputcsv rag_metrics.csv
   | fit DensityFunction latency_ms
   | where isOutlier=1
   | table timestamp query latency_ms
   ```
4. Create Splunk alert: "Notify if latency >500ms"

**Learning:**
- How Splunk detects anomalies
- How to configure alerts
- How to troubleshoot RAG performance

---

### Exercise 4: Groundedness Validation
**Goal:** Show Splunk prevents hallucinations

**Task:**
1. Ask RAG a question NOT in the knowledge base:
   - "What is the capital of France?" (not in lab docs)
2. Observe groundedness score (should be LOW - e.g., 0.3)
3. Ask RAG a question IN the knowledge base:
   - "What is agentic chunking?" (in AI_FUNDAMENTALS.md)
4. Observe groundedness score (should be HIGH - e.g., 0.95)
5. Set Splunk alert: "Flag if groundedness <0.7"

**Learning:**
- What groundedness measures
- How Splunk prevents hallucinations
- How to configure quality alerts
