## 🎓 Usage Flow

### After Installation:

**1. Enable Obsidian Plugin** (one-time, 2 minutes):
```bash
open ~/obsidian_vault
# Settings → Community plugins → Turn OFF Safe mode → Enable "Local REST API"
```

**2. Chat with Your Notes**:
```bash
cd examples
python3 obsidian_chat.py
```

**3. Try Other Examples**:
```bash
python3 summarize_notes.py        # Summarize all notes
python3 build_knowledge_base.py   # Build semantic search
python3 chatbot.py                # General AI chat
python3 rag_example.py            # Document Q&A
```

**4. (Optional) Install Claude Desktop**:
- Downloads from: https://claude.ai/download
- Auto-detects MCP configuration
- Can chat with your notes via Claude!
