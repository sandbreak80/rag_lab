# SME Review Pass (Hybrid C)

**Goal:** Reduce raw 200–300 questions to a curated 150–200 with correct citations and difficulty.

Checklist:
- [ ] Remove duplicates (same intent + same anchor)
- [ ] Fix factual errors; ensure each question is answerable from cited chunks
- [ ] Add 10–20 edge cases per category (observability, security, retrieval)
- [ ] Tag 10–15 "advanced" questions requiring cross-doc synthesis
- [ ] Ensure at least 20 navigational linkcard questions for UI validation
- [ ] Verify perms_tag coverage: public / eng-only / hr-confidential (if applicable)
- [ ] Sanity-scan `expected_citations` format

Tip: Prefer anchors that map to **stable headings** not brittle line ranges.
