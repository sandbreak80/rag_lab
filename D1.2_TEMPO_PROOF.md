## **Configuration Summary**

### **Tempo (docker-compose.yml)**
```yaml
tempo:
  image: grafana/tempo:latest
  container_name: rag-tempo
  command: ["-config.file=/etc/tempo.yaml"]
  ports:
    - "3200:3200"   # Tempo HTTP
    - "4319:4317"   # OTLP gRPC receiver
  volumes:
    - ./monitoring/tempo/tempo.yaml:/etc/tempo.yaml:ro
    - tempo-data:/var/tempo
```

### **OTel Collector (config/otel-collector-config.yaml)**
```yaml
exporters:
  otlp/tempo:
    endpoint: tempo:4317
    tls:
      insecure: true

service:
  pipelines:
    traces:
      receivers: [otlp]
      processors: [memory_limiter, batch, resource]
      exporters: [debug, otlp/tempo]  # ← Exporting to Tempo
```

### **Prometheus (monitoring/prometheus/prometheus.yml)**
```yaml
global:
  exemplar_storage:
    max_exemplars: 100000  # ← Exemplars enabled for trace linking
```

### **Grafana Datasource (monitoring/grafana/datasources/tempo.yml)**
```yaml
datasources:
  - name: Tempo
    type: tempo
    url: http://tempo:3200
    uid: tempo
    jsonData:
      serviceMap:
        datasourceUid: 'prometheus'
      nodeGraph:
        enabled: true
```
