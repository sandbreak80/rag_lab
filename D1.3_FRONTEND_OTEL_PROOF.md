```typescript
export function initializeOpenTelemetry(): void {
  // 1. Resource with service metadata
  const resource = Resource.default().merge(
    new Resource({
      [ATTR_SERVICE_NAME]: 'rag-lab-frontend',
      [ATTR_SERVICE_VERSION]: '1.2.4',
      'service.namespace': 'rag-lab',
      'deployment.environment': 'production',
    })
  );

  // 2. OTLP exporter to OTel Collector via Nginx
  const exporter = new OTLPTraceExporter({
    url: '/api/v1/traces', // Routed through Nginx
  });

  // 3. Auto-instrumentations
  registerInstrumentations({
    instrumentations: [
      new FetchInstrumentation({
        propagateTraceHeaderCorsUrls: [
          /^http:\/\/.*:3000\/api\/.*/,
          /^http:\/\/16\.146\.148\.184:3000\/api\/.*/,
        ],
      }),
      new XMLHttpRequestInstrumentation(),
      new DocumentLoadInstrumentation(),
      new UserInteractionInstrumentation(),
    ],
  });
}
```

## **Proof Artifact #3: Nginx Trace Routing**

**File:** `frontend/nginx.conf` (Lines 42-53)

```nginx
# Frontend traces to OTel Collector (MUST come before /api/v1/)
location /api/v1/traces {
    rewrite ^/api/v1/traces$ /v1/traces break;
    proxy_pass http://otel-collector:4318;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Content-Type application/json;
    proxy_http_version 1.1;
    proxy_read_timeout 30s;
    proxy_connect_timeout 5s;
    add_header Cache-Control "no-store" always;
}
```

**✅ Verification:**
- ✅ Route `/api/v1/traces` → `otel-collector:4318/v1/traces`
- ✅ OTLP HTTP endpoint (port 4318)
- ✅ Content-Type: application/json
- ✅ No caching for trace data

## **Expected Trace Flow**

```
Browser (Frontend)
  ├── Document Load Span
  │   └── service.name: rag-lab-frontend
  │
  ├── User Click (Chat Submit)
  │   └── Fetch: POST /api/v1/rag/query
  │       ├── traceparent: 00-<trace-id>-<span-id>-01
  │       └── Propagated to Backend
  │
  └── Backend Receives Request
      ├── Extracts traceparent header
      ├── Creates child span: rag.query
      │   ├── retrieve.vector
      │   ├── retrieve.web
      │   └── synthesize.llm
      └── All spans share same trace_id
```

## **Web Vitals Captured**

| Metric | Description | Target |
|--------|-------------|--------|
| **CLS** | Cumulative Layout Shift | < 0.1 |
| **FID** | First Input Delay | < 100ms |
| **LCP** | Largest Contentful Paint | < 2.5s |
| **FCP** | First Contentful Paint | < 1.8s |
| **TTFB** | Time to First Byte | < 600ms |

These are sent as custom spans to Tempo with attributes:
- `web_vital.name`
- `web_vital.value`
- `web_vital.rating`
- `web_vital.delta`

## **Troubleshooting**

### **If frontend traces don't appear in Tempo:**

1. **Check browser console for errors:**
   ```
   Failed to fetch /api/v1/traces
   ```
   → Verify Nginx is routing correctly

2. **Check OTel Collector logs:**
   ```bash
   docker logs rag-otel-collector 2>&1 | grep error
   ```

3. **Verify CORS headers:**
   ```bash
   curl -I http://16.146.148.184:3000/api/v1/traces
   ```

4. **Check if traces are batched:**
   Frontend traces are batched every 5 seconds. Wait 10-15 seconds after page load.
