      new FetchInstrumentation({
        propagateTraceHeaderCorsUrls: [
          /^http:\/\/.*:3000\/api\/.*/,
        ],

      new DocumentLoadInstrumentation(),

    ],
  });
}

# **System Architecture: End-to-End Tracing**

```
┌─────────────────────────────────────────────────────────────────┐
│ Browser (Frontend)                                              │
│  ├── Document Load Span (service: rag-lab-frontend)            │
│  ├── User Interaction Span (click, submit)                     │
│  └── Fetch Span: POST /api/v1/rag/query                        │
│      └── traceparent: 00-<trace-id>-<span-id>-01               │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Nginx (Port 80)                                                 │
│  ├── Forwards traceparent header                               │
│  ├── Routes /api/v1/traces → otel-collector:4318               │
│  └── Routes /api/v1/* → rag-api-v1:8080                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ RAG API v1 (Port 8080)                                          │
│  ├── Extracts traceparent header                               │
│  ├── Creates child spans:                                      │
│  │   ├── rag.query (root)                                      │
│  │   ├── retrieve.vector                                       │
│  │   ├── retrieve.web                                          │
│  │   └── synthesize.llm                                        │
│  └── Exports spans to otel-collector:4317                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ OTel Collector (Ports 4317/4318)                                │
│  ├── Receives traces from frontend (HTTP/4318)                 │
│  ├── Receives traces from backend (gRPC/4317)                  │
│  ├── Processes: batch, memory_limiter, resource                │
│  └── Exports to:                                                │
│      ├── Tempo (otlp/tempo:4317) - Trace storage               │
│      └── Debug (console) - Logging                             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Tempo (Port 3200)                                               │
│  ├── Stores traces (local backend)                             │
│  ├── Retention: 1 hour                                          │
│  └── Query API: /api/search, /api/traces/{traceID}             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Grafana (Port 3001)                                             │
│  ├── Datasource: Tempo (http://tempo:3200)                     │
│  ├── Datasource: Prometheus (http://prometheus:9090)           │
│  ├── Exemplars: Link metrics → traces                          │
│  └── UI: Explore → Tempo → View full span tree                 │
└─────────────────────────────────────────────────────────────────┘
```

# **How to Use**

## **View a Trace in Grafana**

1. **Navigate to Grafana:**
   ```
   http://16.146.148.184:3001
   ```

2. **Go to Explore:**
   - Click "Explore" in left sidebar
   - Select "Tempo" datasource

3. **Search for traces:**
   - **By service:** `service.name=rag-api`
   - **By operation:** `name="POST /v1/rag/query"`
   - **By trace ID:** Paste trace ID from API response

4. **View span tree:**
   - Click on any trace
   - See full hierarchy: frontend → nginx → api → retrieval → llm

---

## **Link Metrics to Traces (Exemplars)**

1. **In Grafana, open a dashboard with latency metrics**
2. **Hover over a data point on the graph**
3. **Click "View Trace" button**
4. **Grafana opens the corresponding trace in Tempo**
